
When making a new package release, you should include the following files with the release: 

- `pywrdrb_2.0.1-py2.py3-none-any.whl`
- `pywrdrb_2.0.1.tar.gz`
- `Pywr-DRB-2.0.1.tar.gz` (Automatically generated by GitHub)
- `Pywr-DRB-2.0.1.zip` (Automatically generated by GitHub)


You need to have the `build` and `hatch` packages available. The `hatch` package is _not_ included in the `pywrdrb` dependencies, so you may need to install it into your active environment. 

```bash
pip install build hatch
```

From the `Pywr-DRB/` root directory, run the command:

```bash
hatch build -t wheel -t sdist
```

This should automatically generate the following files in the `dist/` folder:
- `dist/pywrdrb_2.0.1-py2.py3-none-any.whl`
- `dist/pywrdrb_2.0.1.tar.gz`
